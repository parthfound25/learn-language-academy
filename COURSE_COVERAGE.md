## Standard lesson design

All authored lessons are presented through a shared application template:

1. Learning objectives and success criteria
2. Vocabulary with meaning, pronunciation hint, IPA and examples
3. Grammar explanations and usage
4. Useful expressions and contextual examples
5. Practical dialogues with translations
6. Pronunciation and connected-speech guidance
7. Interactive exercises with explanations
8. Speaking activities and lesson review
9. Homework and lesson assessment

For legacy lessons that do not yet contain separately authored objectives, pronunciation notes or homework, the application supplies level-appropriate study guidance derived from the lesson goal, vocabulary and speaking tasks. The 17 new lessons contain these fields explicitly.

## Skills coverage

The course develops all four major skills and interaction/mediation:

- **Listening:** sound recognition, connected speech, fast speech, interviews, media and multi-speaker comprehension. The app currently provides text-based guidance and learner-directed listening tasks; it does not generate audio or score speech.
- **Speaking:** guided pronunciation, dialogues, role-play, spontaneous answers, presentations, debates and capstone discussion.
- **Reading:** sentence comprehension, everyday texts, news, literature, academic texts and critical interpretation.
- **Writing:** sentence construction, paragraphs, messages, formal correspondence, reports, argumentation, synthesis, spelling and proofreading.
- **Interaction and mediation:** clarification, register choice, paraphrasing, summarising for different audiences and culturally aware reformulation.

## Assessment model

- Immediate answer checks with explanations during practice.
- Lesson assessments using each lesson's authored question bank.
- Six level checkpoints at A1, A2, B1, B2, C1 and C2 milestones.
- Revision and homework tasks throughout the course.
- Answer options are shuffled deterministically in lessons and practice so learners cannot rely on a fixed correct-answer position.
- No hearts, lives or failure lockouts. Low scores direct learners to review; they do not prevent continuing.

## Progress and compatibility

- Existing original lesson IDs 1–90 are retained internally, protecting existing completion records.
- New lessons use IDs 91–107 and are inserted into the visible sequence through an explicit insertion map.
- Unlocking follows pedagogical sequence rather than numeric ID order. Previously completed lessons remain reviewable.
- Course totals, progress bars, achievements, learning-path grouping and practice selection use the 107-lesson registry.
- All authored lessons use one shared lesson renderer.
- Learner progress is still held in Streamlit session state in this development build; this update does not claim durable Supabase progress storage.

## Validation

The repository includes automated tests for:
- Original lesson ID coverage (2–90) and extension IDs (91–107).
- The 107-lesson total including the separately authored Lesson 1.
- Required lesson content sections.
- Vocabulary, grammar, examples, conversations, exercises and assessment presence.
- Valid answer indexes and explanations.
- Explicit objectives, pronunciation and homework on all new lessons.
- Python syntax parsing and the application integration anchors.

GitHub Actions runs compilation and curriculum tests on branch pushes and pull requests to main. A passing CI run validates source structure; it does not replace a live Streamlit interaction test or a human review of every pedagogical explanation.
